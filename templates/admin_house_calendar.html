Setting it up in Microsoft 365

The calendar is written by its own app registration, not the mail reader's. An Exchange application access policy limits an app to a set of mailboxes for every permission it holds, so giving the mail reader calendar access would let it write into all the inboxes it reads. A second app, limited to one mailbox, can write the house calendar and nothing else.

  1. The mailbox. Microsoft 365 admin → Teams & groups → Shared mailboxes → Add a shared mailbox, e.g. House, house@chateaugudanes.com. A shared mailbox needs no licence. (An existing one such as reservations@ also works.)
  2. The app. Entra admin centre → App registrations → New registration, Gudanes House Calendar, this organisation only. API permissions → Microsoft Graph → Application permissions → Calendars.ReadWrite, and MailboxSettings.ReadWrite for the area colours. Grant admin consent.
  3. Its secret. Certificates & secrets → New client secret. Copy the value once, straight into Railway.
  4. Limit it to that one mailbox (Exchange Online PowerShell, Connect-ExchangeOnline):
    New-DistributionGroup -Name "GudanesHouseCalendar" -Type Security -Members house@chateaugudanes.com
    New-ApplicationAccessPolicy -AppId <the calendar app's client id> -PolicyScopeGroupId GudanesHouseCalendar@chateaugudanes.com -AccessRight RestrictAccess -Description "House calendar app: the house mailbox only"
    Test-ApplicationAccessPolicy -Identity house@chateaugudanes.com -AppId <client id> should say Granted, and the same for accounts@ should say Denied. It can take up to an hour to apply.
  5. Railway variables: MS_CALENDAR_CLIENT_ID, MS_CALENDAR_CLIENT_SECRET, HOUSE_CALENDAR_MAILBOX (e.g. house@chateaugudanes.com). The tenant is the mail reader's MS_GRAPH_TENANT_ID. Redeploy.
  6. Share it. Come back here and press Share with everybody, read only. Each person then adds it once: Outlook → Calendar → Add calendar → From directory → {{ name }} → Add. It is the house mailbox's own calendar, so it arrives under that name, {{ name }}, with nothing more to choose. It then shows in Outlook on their phone as well.

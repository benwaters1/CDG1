Outlook Add-in

A small panel that shows a guest's room, dinner, and workshop bookings right inside Outlook when you open their email — works in Outlook desktop, Outlook on the web, and Outlook on the web in Safari (there's no separate Safari build; "Outlook on the web" covers it). It also quietly checks every outgoing email for a price or date that doesn't match what's actually on file, and warns before it sends — if the add-in can't be reached for any reason, the email still sends rather than getting stuck. When replying, a "Draft with AI" button can write a first draft grounded in that guest's real history and today's real pricing — always review it before sending.

1. Download the manifest

Right-click and save, or open in a new tab and save the page:

{{ manifest_url }}

2. Sideload it into Outlook

Outlook on the web: Settings (gear icon) → Mail → Customize actions → search "Get Add-ins" → My add-ins → Custom addins → Add a custom addin → Add from file, and choose the manifest you downloaded.

Outlook desktop (Windows/Mac): Home ribbon → Get Add-ins → My add-ins → Custom addins → Add a custom addin → Add from file.

Sideloaded add-ins are per-mailbox — anyone else who wants this (like a family member checking guest emails) repeats this step for their own account. If you'd already installed an earlier version, remove and re-add it — this version asks for read/write access to the open item (needed so "Insert into email" can write the draft in), not just read access.

3. Set the lookup token in the panel

Open any email, click the "Guest Lookup" button in the ribbon, and paste in the same value you set as GUEST_LOOKUP_TOKEN. It's saved to that Outlook profile only — you won't need to re-enter it. The same token also unlocks "Draft with AI" when composing a reply.

4. Reply drafting needs one more key

Set ANTHROPIC_API_KEY (your own Anthropic account's key) as an environment variable. Without it, "Draft with AI" will show an error rather than a draft — everything else on this page works regardless.

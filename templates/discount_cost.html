A discount given without a code — a rate agreed by hand, a goodwill gesture on a bill — is not in here, because there is nothing recorded to count. This page is only as complete as the codes people actually use.

Did any of it work?

This page will not tell you a code “brought in” anything, because nothing can. Whether a guest would have come at full price is unknowable — that guest does not exist to be asked — and a confident wrong answer about marketing spend is worse than none, because it gets repeated.

So the column above is evidence, not a verdict. A code used when the house was nearly full gave money away on rooms that were selling; one used when it was nearly empty at least put somebody in a room. Neither settles it, because a busy night may have been busy because of the code — which is exactly the thing no data can decide.

Occupancy is averaged over the nights a code was used on rather than over the bookings, so a fortnight in a full house weighs more than one night in an empty one. The figure worth holding beside it is on what a night costs: a discounted night is still worth selling as long as it beats what that night actually consumes.

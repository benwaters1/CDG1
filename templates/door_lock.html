Connecting the lock to the site
  1. At iot.tuya.com, create a free account, then Cloud → Development → Create Cloud Project: any name, industry Smart Home, data centre Central Europe. Add the Smart Lock Open Service API when it asks.
  2. In the project, Devices → Link Tuya App Account, and scan the code with the Smart Life app (Me → the scan icon at the top). The lock appears in the list.
  3. From the project's Overview, put the Access ID and Access Secret into Railway as TUYA_ACCESS_ID and TUYA_ACCESS_SECRET (and TUYA_REGION = {{ region }} for Central Europe). They are a key to the house — Railway only, never in an email.
  4. Copy the lock's device ID into the box above, and in the Smart Life app switch remote unlocking on for the lock.
  5. Tuya's free plan runs six months at a time: when it lapses, Cloud → My Services → Extend trial period (a short form, approved in a day or two). The site warns you if the lock stops answering.
